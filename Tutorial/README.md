# Tutorial

The step-by-step tutorial for the PyQt GUI of DRAGen 1.x was removed together with that GUI. It is
still available on the git tag `legacy-baseline`.

DRAGen 2 is installed and run as described in the [README](../README.md#installation): the command
line (`dragen template`, `dragen generate`, `dragen export`) and the browser front end
DRAGen Studio (`dragen gui`).
